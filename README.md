💐 Bouquet Builder

Pixel Bouquet Builder is an experimental front-end web app that allows users to create a custom flower bouquet by selecting pixel-art flowers, leaves, wrapping paper, and ribbon colors, all combined into a live visual mockup.

The project blends design, state management, and visual composition, with a strong focus on rapid iteration and creative development.

🚀 Why this project exists

This app was built using a vibecoding approach, with the goal of learning how to effectively use AI-powered coding tools (such as v0, Bolt, Cursor, and similar) as part of the development workflow.
Instead of treating AI as a code generator, I used it as:
a thinking partner
a rapid prototyping assistant
a way to explore multiple UI and architectural solutions quickly
The emphasis was on speed, experimentation, and learning, rather than on shipping a polished product from day one.

✨ Features

🎨 Pixel-art inspired UI
🌼 Flower selection (multi-select)
🍃 Leaves selection
📦 Wrapping paper color selection
🎀 Ribbon color selection
👀 Live bouquet preview built through layered assets
⚡ Real-time updates based on user choices

🧠 Technical Overview
Framework: React + TypeScript
Styling: Tailwind CSS
State Management: React hooks (useState)
Architecture: Component-based, scalable
Rendering Strategy: Image layering for bouquet composition
Backend: None (front-end only, v1)
The bouquet preview is generated by stacking visual layers in a defined order:
Wrap (base)
Leaves
Flowers (multiple layers)
Ribbon (top)

This approach keeps the logic simple while allowing high visual flexibility.
